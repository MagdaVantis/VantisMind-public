# Vantis Mind – strona wizytówka

Strona agencji Vantis Mind publikowana przez GitHub Pages.

## Jak włączyć stronę
1. Settings → Pages
2. Source: **Deploy from a branch**, Branch: **main**, folder **/ (root)** → Save
3. Po 1–2 minutach strona działa pod adresem `https://magdavantis.github.io/VantisMind-public/`

## Własna domena vantismind.pl
1. Settings → Pages → Custom domain: `vantismind.pl` → Save
2. W panelu home.pl dodaj rekordy DNS:
   - A → 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153
   - CNAME `www` → `magdavantis.github.io`
3. Po propagacji zaznacz **Enforce HTTPS**.
